# Do / Don't

Use this file when the output starts drifting away from the intended Codex-like visual character.

| Do | Don't |
|---|---|
| Use cold white and pale blue surfaces as the dominant canvas | Fill large areas with deep blue |
| Keep blue as emphasis for actions and active states | Use blue as the main background color |
| Use pure white cards with thin borders | Turn every card into a gradient tile |
| Use subtle, low-noise depth | Stack heavy shadows and glows |
| Prefer linear icons and precise controls | Use decorative, bloated, or glossy icon treatment |
| Make active states clear and calm | Make active states neon or over-lit |
| Make cards feel like workbench modules | Make cards feel like promo banners |
| Use one restrained visual language across the page | Mix glass, neon, marketing gradients, and enterprise chrome on one screen |

## Fast Smell Tests

If the UI looks like any of the following, it has probably drifted:

- “too startup landing page”
- “too glowing”
- “too blue”
- “too soft and jelly-like”
- “too decorative for an operational tool”

When that happens, bias back toward:

- white
- border
- pale blue
- alignment
- structure
- clarity
