# Dashboard Example

Use this file when the user wants a Codex-light overview page, workbench home, or summary dashboard.

## Intent

This page type should feel like an operational launch surface:

- one strong overview panel
- a few secondary cards
- clear next actions
- low-noise metrics

It should not feel like a landing page hero.

## Recommended structure

1. top summary panel
2. two to four support cards
3. recent activity / exports / alerts / history

## Surface behavior

- top panel may be the largest surface, but it remains white and restrained
- support cards stay mostly white with thin borders
- use blue for one primary action and selected metadata only
- metrics should rely on typography first, color second

## Suggested content blocks

- inventory status
- export files
- recent activity
- automation health
- quick actions

## Prompt-ready implementation note

If implementing this page, preserve:

- cold white canvas
- pale-blue active chips
- one primary CTA maximum per cluster
- light structure from borders and spacing

## Smell tests

The page is drifting if:

- the top block becomes a marketing hero
- every card looks equally loud
- blue fills dominate the viewport
- decorative gradients appear inside normal cards
