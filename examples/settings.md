# Settings Example

Use this file when the user wants a Codex-light settings page, preferences screen, or configuration panel.

## Intent

A settings surface should feel trustworthy, calm, and easy to scan repeatedly.

## Recommended structure

1. small page summary
2. grouped settings cards
3. local helper text
4. one obvious save/apply action

## Surface behavior

- settings groups should be white cards with clear borders
- helper text stays secondary and short
- form controls should feel part of the same panel family as cards
- focus uses crisp border/ring treatment, not glow

## Suggested content blocks

- refresh policy
- retention policy
- export behavior
- import scanning behavior
- automation toggles

## Prompt-ready implementation note

If implementing this page, preserve:

- medium density
- quiet card grouping
- stable white surfaces
- blue only for primary save/apply emphasis and active controls

## Smell tests

The page is drifting if:

- settings cards feel more decorative than operational
- helper text turns into product marketing
- control states are inconsistent
- every group competes equally for attention
