## Codex Light UI Style

可复用的浅色冷白蓝 UI 风格提示词，适合用于后台、工作台、桌面工具、管理台、数据面板、导入导出工具等界面。

### 短版提示词

```text
请将当前界面重构为一种类似 Codex app 的浅色冷白蓝工具风格：整体以高亮度、低饱和、低噪音为主，背景使用冷白或极浅蓝白，面板以纯白为主，边框细且清晰，阴影非常轻。强调色只使用少量品牌蓝，不要让整页变成重蓝色科技风。卡片不要使用明显渐变，优先纯白 + 1px 浅蓝灰边框 + 轻阴影。导航激活态使用浅蓝底，不要整条深蓝。图标优先线性图标，默认灰蓝，激活时变品牌蓝。按钮默认白底浅蓝边，主按钮纯蓝底白字。避免大面积深蓝背景、霓虹渐变、过多发光、毛玻璃和高透明拟态。
```

### 长版提示词

```text
请参考 Codex app 一类的浅色冷白蓝视觉气质来优化当前前端 UI，但只借鉴色彩搭配、材质层次、边框阴影和组件气质，不照搬具体功能布局。

目标视觉气质：
- 高亮度、低饱和、低噪音
- 白色工作台感，而不是重蓝科技面板
- 更像专业工具界面，而不是营销页或炫光大屏

配色结构：
- 背景底色：#F7FAFD 或 #F5F8FC
- 主面板：#FFFFFF
- 次级面板：#F8FBFF
- 边框：#DCE7F3
- 主文字：#171A1F
- 次文字：#687386
- 强调蓝：#2F91FF 或 #339CFF
- Hover 蓝雾：#EAF4FF
- 激活浅蓝底：#DDEEFF

视觉效果：
- 大背景允许 very soft gradient：linear-gradient(180deg, #F8FBFF 0%, #EEF5FC 100%)
- 卡片不要渐变，优先纯白 + 细边框
- 阴影压低，建议使用 0 8px 24px rgba(120, 160, 210, 0.08) 或更轻
- 不使用玻璃拟态，不使用高饱和蓝光，不堆叠发光效果

组件气质：
- 默认按钮：白底 + 浅蓝边 + 深色字
- 主按钮：纯蓝底 + 白字
- 导航激活态：浅蓝底，不要整条深蓝
- 图标：优先线性图标，默认灰蓝，激活时变品牌蓝
- 卡片：14–18px 圆角、1px 边框、轻阴影或无阴影

避免方向：
- 避免大面积深蓝背景
- 避免高对比霓虹渐变
- 避免每个区块都发光
- 避免大量半透明毛玻璃

输出时请优先落地为：
1. 更统一的颜色变量
2. 更克制的面板与卡片样式
3. 更轻的阴影与边框
4. 更一致的按钮、导航、图标视觉系统
```

### CSS Token 草案

```css
:root {
  --ui-bg: #F7FAFD;
  --ui-bg-alt: #F5F8FC;
  --ui-panel: #FFFFFF;
  --ui-panel-soft: #F8FBFF;
  --ui-border: #DCE7F3;
  --ui-text: #171A1F;
  --ui-text-muted: #687386;
  --ui-accent: #339CFF;
  --ui-accent-strong: #2F91FF;
  --ui-accent-soft: #EAF4FF;
  --ui-active-bg: #DDEEFF;
  --ui-bg-gradient: linear-gradient(180deg, #F8FBFF 0%, #EEF5FC 100%);
  --ui-shadow-soft: 0 8px 24px rgba(120, 160, 210, 0.08);
  --ui-radius-card: 18px;
  --ui-radius-control: 14px;
}
```

### 使用建议

- 如果是让模型直接改页面，优先使用“长版提示词”
- 如果是快速给一个视觉方向，优先使用“短版提示词”
- 如果要改已有项目，先抽出颜色变量，再统一按钮 / 卡片 / 导航 / 图标
